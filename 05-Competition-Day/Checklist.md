# Competition Day Checklist

Essential items and preparations for the in-person competition at ACC 2026.

---

## ✈️ Travel & Logistics

### Documentation
- [ ] **Visas** to USA (if required)
- [ ] **Travel tickets** booked and confirmed
- [ ] **Hotel accommodations** arranged
- [ ] Conference **registration** confirmed

### Location
- **Event**: American Control Conference 2026
- **City**: New Orleans, Louisiana, USA
- **Dates**: May 26-28, 2026

---

## 💻 Technical Equipment

### Networking (CRITICAL)
- [ ] **Router** - For QCar communication
- [ ] **Network Switch** - Multiple device connection

> [!WARNING]
> Past teams have had issues connecting to their QCar due to unreliable venue networks. **Bring your own networking equipment!**

### Computing
- [ ] **Development laptops** (charged, with power adapters)
- [ ] **Portable monitors** (for extended workspace)
- [ ] **Keyboards and mice** (for comfortable development)
- [ ] **Extension cords** (venue outlets may be limited)

### Storage
- [ ] **USB drives** with backup code
- [ ] **External hard drives** (optional, for data)

---

## 📦 Competition Materials

### Code & Documentation
- [ ] Latest code version deployed and tested
- [ ] Backup copies on multiple devices
- [ ] Quick reference documentation printed/saved

### Testing
- [ ] Verified algorithm works in QLabs
- [ ] Tested with various scenarios
- [ ] Practiced ride execution

---

## 🔌 Connectivity

### QCar 2 Connection

For reliable QCar connectivity, you need:

| Equipment | Purpose |
|-----------|---------|
| **Router** | Create private network |
| **Network Switch** | Connect multiple devices |
| **Ethernet cables** | Wired connections |

### Reference Documentation
- [User Manual for Connectivity](https://github.com/quanser/Quanser_Academic_Resources/blob/dev-windows/3_user_manuals/qcar2/user_manual_connectivity.pdf)

## 📋 Pre-Competition Tasks

### Week Before
- [ ] Final algorithm testing and validation
- [ ] Pack all equipment
- [ ] Confirm travel and accommodations
- [ ] Download all documentation offline

### Day Before
- [ ] Charge all laptops and devices
- [ ] Test network equipment
- [ ] Review competition rules
- [ ] Prepare ride strategy

### Competition Day
- [ ] Arrive early for setup
- [ ] Set up networking first
- [ ] Test QCar connectivity
- [ ] Review ride coordinates
